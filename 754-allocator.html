Paste Partners from Excel

Paste rows copied from Excel. Two formats accepted:

  One column: Name  (initial shares default to 0)

  Two columns: Name <TAB> Initial Shares

A header row (e.g. first row is literally "Name" / "Partner") is auto-skipped. Existing partners are kept; pasted rows are appended.

Import Transaction from Excel

One transaction per import. Set the metadata below, then paste the participant rows.

Paste participants — each row is one partner's role in this transaction. Two accepted formats:

  2 columns: Partner ID <TAB> Shares  (negative or (N) parentheses = sold)

  3 columns: Partner ID <TAB> Role <TAB> Shares  (role = buyer/seller/bought/sold/in/out)

Partner ID may also be the partner's name (case-insensitive match). Header row auto-skipped.
